# Satellite-Altimetry-and-Physical-Oceanography

Python Jupyter Notebooks for students of the 'Satellite Altimetry and Physical Oceanography' course at TUM.

## Environment Setup

To ensure code reproducibility and avoid library conflicts, it is highly recommended to use the provided Conda environment. 

**1. Clone the repository to your local machine:**
```bash
git clone https://github.com/giulia-tafuni/Satellite-Altimetry-and-Physical-Oceanography.git
cd Satellite-Altimetry-and-Physical-Oceanography
```

**2. Create the virtual environment using the provided `environment.yml` file:** 
```bash
conda env create -f environment.yml 
```

**3. Activate the environment:**
```bash
conda activate class_env
```
